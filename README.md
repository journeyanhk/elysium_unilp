# Elysium LP 管理器（KNTQ/HYPE）

面向 Elysium 链上 Uniswap V4 风格部署的 LP 管理工具：组池 / 领费 / 撤池 + 只读看板 + 模拟器。

**安全原则**：预览 → 模拟 → 逐笔签名；只允许白名单合约；不托管私钥；不自动放宽滑点、不自动重发交易。

> ⚠️ 当前状态：M0 之前（脚手架 + 方案）。**合约身份核验通过前，交易功能不开放。**

- 方案与计划：[PLAN.md](PLAN.md)（当前 v0.3）
- 协作流程：每阶段一个 Pull Request，review 通过后进入下一阶段
- 目录：`frontend/`（界面）、`backend/`（数据服务）
